# 제작 작업실 리뉴얼

## 새 순서

아이디어·기획 → 캐릭터 → 세계관·설정집 → 스토리 구조 → 회차·대본 → 콘티·작화 → 검수·완성.

단계 목록은 src/lib/utils.ts의 STEPS에서 관리하며 작업실 내비게이션, 대시보드 이동, 홈페이지, 제작 가이드가 이를 공유한다. 제작 가이드 설명은 src/lib/creationGuide.ts에서 관리한다.

## 입력과 저장

- 기획 카드: 제작 방식, 단편/한 화/연재, 목표 컷 수, 아이디어, 분위기, 독자, 감정, 목표, 꼭 지킬 설정. 자동 저장.
- 캐릭터: 목표, 두려움, 약점, 성장, 말투, 관계 추가. 기존 디자인 시트 유지.
- 세계관: 시대, 무대, 가능/금지/대가, 반복 장소, 물건, 확정/미정 설정, 복선 기록. 별도 화면에서 저장.
- 스토리: 중심 갈등과 실패의 대가, 다섯 단계 이야기 구조.
- 회차·대본: 제목, 시놉시스, 회차 목표, 장애물, 새로운 정보, 마지막 장면을 대본 앞에서 편집.
- 콘티: 컷 목적, 감정, 연속성 메모, 짧음/보통/긴 여백. 세로 미리보기에 여백 반영.
- 창작 내용 변경 시 검수 체크와 완성 표시 해제. 내용이 같은 저장은 유지.

## AI 연결

채팅·자동 초안·컷 설계에 기획과 설정집 자료를 전달한다. 직접 작성한 기획만으로도 자동 초안을 요청할 수 있다. 대본은 선택한 회차를 명시하며, 새 캐릭터 초안은 기존 인물을 삭제하지 않고 추가된다. 캐릭터·스토리 응답 스키마도 새 항목을 포함한다. 그림 생성에는 세계관과 컷의 연속성 메모를 기존 시각 맥락으로 전달한다.

함께 만들기 / AI 초안부터 / 직접 만들기는 멘토의 응답 지침을 조정한다. 아이디어·기획만으로 각 단계의 AI 채우기를 사용할 수 있다. 여러 단계를 한 번에 실행하는 백그라운드 일괄 제작은 아니며 이미지 생성은 기존 버튼으로 별도 요청한다.

### AI 초안 우선 입력

- 새 캐릭터 자동 생성은 인물 서사와 외형 고정 12항목을 함께 반환한다.
- 기존 캐릭터의 외형 AI 채우기는 현재 화면의 미저장 이름·나이·외모·성격·배경·추가 이미지 지시와 작품 기획을 참고한다.
- 세계관 AI 채우기는 시대·무대·가능/금지/대가·장소·소품·미정 후보·복선 초안을 작성한다. 사용자 확정 설정은 생성 대상에서 제외한다.
- 선택 회차의 제목·시놉시스·목표·장애물·새 정보·마지막 장면을 별도로 채울 수 있다. 대본 생성도 비어 있는 회차 설계와 대본을 함께 반환한다.
- 작가 노트 AI 초안을 제공하되 실제 경험·수상·제작 시간·AI 기여 비율을 지어내지 않도록 요청한다. 검수 체크나 완성 승인은 자동으로 수행하지 않는다.
- 새 필드별 버튼은 빈칸 채우기가 기본이다. 전체 다시 제안은 기존 내용 변경 확인 후 실행한다. 요청 중 사용자가 바꾼 입력은 보존한다.
- 불완전한 AI 응답은 서버에서 거부하며 요청 오류·시간 초과를 표시한다. 외형 생성은 이미지 자산이나 캐릭터 ID를 변경하지 않는다.
- 세계관의 확정·미정·복선은 편집 가능한 텍스트이며 변경 승인 이력이나 자동 복선 검증기는 아니다.

## 호환성과 검증

workflowVersion 2로 기존 단계 번호를 한 번만 이전하고 캐릭터 이미지 참조, 대본, 컷을 보존한다. 새 필드에는 기본값을 채운다. JSON 백업에 새 필드가 포함되며 텍스트 다운로드도 새 설정과 대본→콘티 순서를 반영한다.

node scripts/verify-renewal.cjs: 이전의 멱등성, 데이터 보존, 검수 무효화, 설정 전달, 회차 선택, AI 제작 모드, 컷 메타데이터, 가이드 순서와 외형·세계관·회차 설계·대본·작가 노트 응답 검사. 누락 응답 거부와 편집 중 입력 보존도 검사한다. 외부 AI 호출은 모킹한다.
node scripts/verify-project-context.cjs: 개인정보 메타데이터 제외와 맥락 크기 제한 검사.
node scripts/verify-ai-fill-ui.cjs: AI 채우기 컴포넌트의 중복 요청 방지, 빈칸 처리, 전체 재생성 확인, 오류 시 미적용, 언마운트 취소 검사. 브라우저 대신 컴포넌트 하네스를 사용한다.

브라우저 연결이 없어 클릭과 시각 검증은 미실시. 실제 유료 AI 생성의 품질도 별도 확인이 필요하다.
